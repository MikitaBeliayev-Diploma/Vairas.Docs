## scheduling_request

One revision of a school-owned initial schedule input/proposal; status metadata is distinct from lesson lifecycle.

Source model note: Request revision identifies an exact frozen input/candidate basis, not the concurrency revision of a lesson. Submitted/Ready/Confirmed states require validated complete input when entered. Confirm exact request id/revision and revalidate current sources. Confirmed input/candidates are never regenerated in place. Rejected validation does not imply a valid submitted snapshot. Metadata CHECKs are generated by EF Core. Dates are interpreted in configured Europe/Vilnius. Revision immutability, same-school ownership and lifecycle transitions are guarded by application services and authorization.

**Row CHECKs:**

- `ends_at > starts_at` — assessment_interval.
- `(kind = 'Practical' AND vehicle_id IS NOT NULL) OR (kind = 'Theory' AND vehicle_id IS NULL)` — assessment_type.

**Lifecycle / immutable / audit:** See the current context contract and local SQL companion; service-only rules are not falsely certified by row CHECKs.
